# 양자, 처음부터

**과학을 처음 배우는 사람을 위한 한국어 양자컴퓨터 인터랙티브 교재.** 중·고등학교 과학 수준에서 출발해 수식의 의미를 애니메이션, 그래프, 슬라이더, 모의 측정으로 확인합니다.

**[브라우저에서 바로 읽고 실험하기 →](https://aidevksh.github.io/quantum_computer/)**

React·TypeScript·Vite로 작성했습니다. 10개 장의 학습 흐름에 **개념 애니메이션 8편, 직접 조작하는 실험 8개, 수식별 기호 해설, 퀴즈 6문항**을 제공합니다.

## 로컬에서 실행

Node.js **22.12 이상**이 필요합니다. 저장소를 내려받은 뒤 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 **http://127.0.0.1:4173** 에 접속합니다. 이 버전은 Vite의 모듈 빌드를 사용하므로 소스의 `index.html`을 더블클릭하는 대신 개발 서버나 빌드 미리보기 서버를 사용하세요.

교재는 브라우저 안에서 계산하며 계정·API 키·원격 양자 장치가 필요하지 않습니다. 글꼴·영상·계산 기능을 외부 서비스에서 불러오지 않습니다. 패키지 설치와 출처 원문 열기에는 인터넷이 필요합니다. 인터넷 없는 환경에서는 의존성을 미리 설치하고 빌드한 파일을 로컬 정적 서버로 제공하면 됩니다.

## 그림의 변화를 따라가는 애니메이션

각 애니메이션은 네 단계의 그림과 한국어 자막을 같은 시간축에 맞춥니다. **재생·일시정지, 다시 보기, 시간 탐색, 단계 이동, 재생 속도 조절**로 중간 과정을 반복해서 볼 수 있습니다. 소리는 없습니다. 화면 밖이나 숨긴 탭에서는 재생을 멈추고, 운영체제의 동작 줄이기 설정을 존중합니다.

| 애니메이션 | 그림에서 따라가는 변화 |
|---|---|
| 두 경로의 간섭 | 두 파동의 합 → 보강·상쇄 → 검출 분포 |
| 큐비트와 진폭 | 화살표의 두 성분 → 진폭의 크기 → 제곱한 확률 |
| 위상과 H–P–H | 복소수 화살표 회전 → 진폭을 다시 섞기 → 측정 확률 |
| 벨 얽힘 | 두 큐비트 준비 → H → CNOT → 공동 측정 결과 |
| 그로버 탐색 | 같은 진폭 → 정답의 위상 반전 → 평균 반사 → 확률 증폭 |
| 큐비트 수와 상태 공간 | 두 갈래씩 늘어나는 기준 상태 → 2ⁿ 증가 → 비트열 하나 측정 |
| 결맞음 손실 | 상태 지도 안쪽으로 짧아지는 화살표 → 낮아지는 간섭 대비 |
| 온도와 에너지 간격 | 냉각 → 열 에너지 감소 → 높은 준위의 열평형 비율 감소 |

[3Blue1Brown의 벡터 설명](https://www.3blue1brown.com/lessons/vectors/)과 [그로버 알고리즘 설명](https://www.3blue1brown.com/lessons/grover/)을 참고해 **수·기호·그림을 함께 변화시키는 설명 방식**을 적용했습니다. 이 저장소의 SVG 장면과 한국어 설명은 직접 작성했으며 원본 영상이나 그래픽을 포함하지 않습니다.

## 수식을 읽는 방법

수식마다 소리 내어 읽는 법과 기호별 버튼이 있습니다. 기호를 누르면 **이름·뜻·역할·단위·숫자 예시**를 확인합니다. 진폭의 제곱, 각도, 복소수 위상, 광자 에너지, 지수적 감쇠, 온도 변환 등에는 조작 가능한 작은 그림을 연결했습니다.

`|ψ⟩` 같은 상태 이름과 절댓값 `|α|`, 위상 `φ`와 원주율 `π`, 진폭과 확률처럼 혼동하기 쉬운 표기를 구분합니다. 수식을 외우기보다 값을 바꾸어 그림이 어떻게 달라지는지 보는 데 초점을 맞췄습니다.

## 자료를 읽는 기준

현황은 기준일 이전에 확인한 **주요 이정표를 선별한 자료**입니다. 모든 제품의 실시간 목록이나 업체별 성능 순위가 아닙니다. 대표 발표일, 실증 범위, 장래 목표와 해석상의 한계를 함께 읽어야 합니다. 물리 큐비트·논리 큐비트·알고리즘 큐비트 등의 수치는 정의와 시험 조건이 달라 단순 비교할 수 없습니다.

## 모형의 범위

이 문서는 일반 컴퓨터의 수치 계산으로 양자 모형을 시각화합니다. 실제 양자 하드웨어에 접속하지 않습니다.

- 간섭 실험은 슬릿의 실제 크기·거리·단위를 생략한 분포 모형입니다. 검출 점은 정규화한 분포에서 무작위로 뽑습니다.
- 단일 큐비트, H–P–H, 벨 상태, 그로버 탐색은 이상적인 게이트를 가정합니다. 반복 측정은 매번 같은 상태를 새로 준비하는 상황입니다.
- 벨 실험은 두 상태를 비교하는 교육용 모형입니다. 실제 장치의 얽힘 인증이나 벨 부등식 검증 실험이 아닙니다.
- 그로버 예시는 후보 4개·정답 1개인 특별한 경우입니다. 애니메이션의 연속 변화는 정규화된 수학 모형이며 실제 제어 펄스를 재현하지 않습니다. 질의 횟수의 이점과 실제 실행 시간은 다릅니다.
- 2ⁿ은 기준 상태 수입니다. 한 번에 2ⁿ개의 답을 읽거나 실제로 컴퓨터 2ⁿ대가 생긴다는 뜻이 아닙니다.
- 결맞음 손실은 T₂=40 μs로 정한 순수 위상감쇠 모형입니다. 특정 제품의 사양이 아닙니다.
- 온도 실험은 5 GHz의 두 에너지 준위가 열평형에 있다는 이상화입니다. 들뜸 확률은 전체 오류율이 아니며 고온까지 연장한 식은 초전도 칩의 실제 작동 범위를 뜻하지 않습니다.

## 검증과 빌드

```sh
npm run typecheck
npm test
npm run build
```

TypeScript의 타입 검사와 수학 모형 테스트를 실행합니다. 테스트는 상태 정규화, 위상·간섭의 경계값, 그로버 탐색, 열평형의 극한 등을 확인합니다. `npm run build`는 타입 검사 후 Vite로 정적 파일을 `dist/`에 생성합니다.

빌드 결과를 로컬에서 확인합니다.

```sh
npm run preview
```

**http://127.0.0.1:4173** 에 접속합니다. 배포할 때에는 `dist/` 전체를 정적 호스팅 서비스에 올립니다. 빌드의 상대 경로 설정은 GitHub Pages의 `/quantum_computer/` 주소를 지원합니다.

브라우저 동작을 검증합니다.

```sh
npm run test:browser
```

브라우저 테스트는 빌드와 미리보기 서버의 시작·종료를 직접 처리합니다. 다른 개발 서버가 4173 포트를 사용 중이면 먼저 종료하세요. macOS에서는 설치된 Google Chrome을 사용합니다. 다른 환경에서는 `npx playwright install chromium`으로 테스트 브라우저를 설치하거나 `CHROME_PATH`로 Chrome 실행 파일을 지정합니다. 장 이동, 애니메이션 제어, 기호 해설, 주요 실험, 검색·퀴즈와 모바일 화면을 검증합니다.
