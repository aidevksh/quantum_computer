# 양자, 처음부터

**과학을 처음 배우는 사람을 위한 한국어 양자컴퓨터 인터랙티브 교재.** 중·고등학교 과학 수준에서 출발해 수식의 의미를 그래프, 슬라이더, 모의 측정으로 확인합니다.

**[브라우저에서 바로 읽고 실험하기 →](https://aidevksh.github.io/quantum_computer/)**

순수 HTML·CSS·JavaScript로 구성한 정적 문서입니다. 읽고 실험하는 데 서버, 계정, API 키, 외부 라이브러리나 인터넷 연결이 필요하지 않습니다. 참고 자료의 원문 링크를 열 때에는 인터넷이 필요합니다.

## 바로 열기

저장소를 내려받은 뒤 **`index.html`을 더블클릭**하면 됩니다. `assets/`, `data/` 폴더도 함께 보관하세요. JavaScript를 허용한 브라우저가 필요합니다.

개발용 로컬 서버를 사용하려면 Node.js 환경에서 실행합니다.

```sh
npm run dev
```

브라우저에서 **http://127.0.0.1:4173** 에 접속합니다. 문서 실행과 기본 개발 서버에는 패키지 설치가 필요하지 않습니다.

## 자료를 읽는 기준

조사 기준일은 **2026년 11월 7일**입니다. 기초 개념은 원논문과 공식 교육 자료, 현황은 연구기관·기업의 공식 발표와 논문을 중심으로 조사했습니다. 본문 설명 옆의 출처와 마지막 장의 참고 자료에서 원문을 확인할 수 있습니다.

현황 표는 기준일 이전에 확인한 **주요 이정표를 선별한 자료**입니다. 모든 제품을 실시간으로 나열하거나 업체별 성능 순위를 매긴 자료가 아닙니다. 각 항목의 대표 발표일, 실증 범위, 회사의 장래 목표와 해석상의 한계를 함께 읽어야 합니다. 물리 큐비트·논리 큐비트·알고리즘 큐비트 등의 수치는 정의와 시험 조건이 달라 단순 비교할 수 없습니다.

조사 과정과 수식 검토는 다음 파일에 정리했습니다.

## 실험 모형의 범위

이 문서는 브라우저에서 고전적인 수치 계산으로 양자 모형을 시각화합니다. 실제 양자 하드웨어에 접속하지 않습니다.

- 간섭 실험은 슬릿의 실제 크기·거리·단위를 생략한 분포 모형입니다. 검출 점은 모형의 확률분포에서 무작위로 뽑습니다.
- 단일 큐비트와 H–P–H, 벨 상태, 그로버 탐색은 이상적인 게이트를 가정합니다. 반복 측정은 매번 같은 상태를 새로 준비하는 상황입니다.
- 벨 실험은 두 상태를 비교하는 교육용 모형입니다. 실제 장치의 얽힘 인증이나 벨 부등식 검증 실험이 아닙니다.
- 그로버 실험은 후보 4개·정답 1개인 특별한 경우입니다. 질의 횟수의 이점과 실제 실행 시간은 다릅니다.
- 2ⁿ은 기준 상태의 개수입니다. 한 번 측정해서 2ⁿ개의 답을 모두 읽을 수 있다는 뜻이 아닙니다.
- 결맞음 손실은 T₂=40 μs로 정한 순수 위상감쇠 모형입니다. 특정 제품의 사양이 아닙니다.
- 온도 실험은 5 GHz의 두 에너지 준위가 열평형에 있다는 이상화입니다. 들뜸 확률은 전체 오류율이 아니며, 높은 온도까지 연장한 식은 초전도 칩의 실제 작동 가능 범위를 뜻하지 않습니다.

## 검증과 빌드

수학 모형의 정규화, 위상·간섭의 경계값, 그로버 탐색, 열평형의 극한, 오류 확률 등을 검증합니다.

```sh
npm test
```

브라우저 검증에는 개발 의존성인 Playwright를 설치합니다.

```sh
npm install
npm run test:browser
```

테스트가 로컬 서버를 직접 시작하고 종료합니다. macOS에서는 설치된 Google Chrome을 사용합니다. 다른 환경에서는 `npx playwright install chromium`으로 테스트용 브라우저를 설치하거나 `CHROME_PATH` 환경변수로 Chrome 실행 파일을 지정하세요. 자세한 내용은 [테스트 스크립트](tests/browser.cjs)를 참고하세요. 이 의존성은 교재 자체를 여는 데에는 필요하지 않습니다.

배포용 정적 파일을 복사합니다.

```sh
npm run build
```

결과는 `dist/`에 생성됩니다. `dist/index.html`도 직접 열 수 있으며, `dist/` 폴더 전체를 정적 호스팅 서비스에 올릴 수 있습니다.
